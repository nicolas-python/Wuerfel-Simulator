# Würfel Simulator 

Ein einfaches Python Programm das einen Würfel simuliert.Die Würfel werden als ASCII-Bild dargestellt.

## Funktion 

 Zwei Würfel werden zufällig gewürfelt
- Anzeige der gewürfelten Zahlen
- Anzeige der Würfel als ASCII-Bild
- Berechnung der Gesamtsumme
- Möglichkeit erneut zu würfeln

## Nutzung

Starte das Programm mit:

Python wuerfel_simulator.py

Das Programm würfelt automatisch beim Start.  
Am Ende kann man entscheiden, ob man noch einmal würfeln möchte oder das Programm beenden will
